# 截图模板编辑器

本项目以 MIT License 发布。项目中的第三方字体和 OCR 组件分别遵循其随附的许可证。

在浏览器中填写空白截图模板，并导出图片。请假详情提供 1、2、3 节课三种布局，另有流程跟踪模板。自行导入的图片可在浏览器内识别信息字段。

四个内置模板已裁掉截图顶部的手机状态栏。两节课模板保留参考图中的“附件信息”边框和黑色缩略图，可以在右侧选择图片替换原缩略图；清空后恢复参考图中的黑色缩略图。自选附件只在当前会话中使用，并随导出的图片保存。

## 启动

需要 Node.js 18 或更高版本。在项目目录运行：

```powershell
npm ci
npm run dev
```

打开终端显示的地址，默认是 <http://127.0.0.1:5173/>。生产构建运行 `npm run build`，结果写入 `dist`。

## Windows 桌面版

运行 `npm run desktop:run` 可直接打开本地桌面窗口；运行 `npm run desktop:pack` 会构建单文件便携版，输出到 `release/ScreenshotTemplateEditor-版本号-portable.exe`。便携版双击运行，无需启动网页服务。模板、字体和识别模型均随程序打包；网页站点的更新需另外部署。

## Android 安装版

已构建的 APK 位于 `release/ScreenshotTemplateEditor-0.6.2-android.apk`。将 APK 复制到 Android 手机后，在手机文件管理器中打开并安装。系统首次安装来自文件管理器的应用时，可能要求允许该来源安装应用。安装后可离线使用内置模板、字体和 OCR；导出 PNG/JPG 时通过系统保存窗口选择目录。

要在 Windows 上重新构建，先安装 JDK 21 和含 Android API 36 的 SDK，设置 `JAVA_HOME`、`ANDROID_HOME`，然后运行 `npm ci` 和 `npm run android:apk`。脚本会构建网页资源、同步 Capacitor Android 工程，并输出用于个人测试的调试签名 APK。重新构建时使用 `android/` 中的原生代码；不要只复制 `dist`。

如果当前网络让 Gradle 访问 Maven Central 时出现 TLS 握手错误，可另开一个终端运行 `python scripts/local-maven-proxy.py`，在构建终端先执行 `$env:LOCAL_MAVEN_BRIDGE='1'`，再运行 `npm run android:apk`。这只为本机编译缓存依赖，APK 不依赖该服务。

## 从其他设备访问

- **同一局域网**：在这台电脑运行 `npm run dev:lan`，然后在另一台连接同一网络的设备打开 `http://这台电脑的局域网IP:5174/`。可用 `ipconfig` 查看 WLAN 的 IPv4 地址。如果无法连接，检查 Windows 防火墙是否允许 Node.js 在专用网络接收入站连接。
- **不同地点**：两台设备登录同一个 Tailscale 网络，在这台电脑运行 `npm run dev:lan`，然后在另一台设备打开 `http://这台电脑的Tailscale-IP:5174/`。用 `tailscale ip -4` 查看地址。如需专属 HTTPS 域名，可另行启用 Tailscale Serve；首次使用可能需要在其管理页开启该功能。

电脑与开发服务需保持运行。页面没有登录功能，局域网模式只应在可信网络使用；不要直接做公网端口映射。

如果有 Ubuntu 服务器和公网域名，可按 [DEPLOY.md](DEPLOY.md) 把静态构建部署到 Nginx，电脑关闭后仍可访问。

## 使用

1. 左侧选择“请假详情 · 1/2/3 节课”或“流程跟踪”，原有信息已空白，右侧直接填值。也可以点“导入图片”选择自己的截图。
2. 模板显示“已校准 N 个字段”；导入图片需等待“已识别 N 个字段”。系统只自动标出已知的学生、请假和流程信息字段，忽略标题、按钮等非字段内容。画布虚线框表示位置。
3. 修改右侧字段，并按需要调整字体、字号、水平和垂直偏移。同名学生信息会同步到当前会话内的其他图片。两节课模板可在“附件信息”中选择或清空附件图片。
4. 导入图片识别错了字段名称时，可直接改名；漏检时点“框选补充”，在画布上拖出文字区域并输入新内容。也可重新识别。
5. 选择 PNG 或 JPG 并导出，导出图不含定位框。“重置全部修改”会清空全部模板的填写值，同时还原导入图片的修改。

“导入图片”可处理临时图片。“导入 TXT 模板”支持每行一个 `字段：新值`，例如：

```text
姓名：示例姓名
学号：0000000000
请假天数：0.5天
```

同一张图片中重复出现的字段（例如多门课程的“课程名称”）可以逐项在右侧编辑。

## 苍水行楷字体

内置字体包含霞鹜文楷、马善政毛笔、思源黑体和思源宋体。另有 TTF、OTF、WOFF 或 WOFF2 文件时，可点左侧“导入字体文件”，然后在字段字体菜单选择“已导入”；这类额外导入的字体只在当前浏览器会话加载，不会上传到服务器。

## 识别范围与限制

- 模板的字段位置保存在 `original-presets.js`，初始值均为空。发布用的 `public/assets/blank-*.png` 不含原字段值；原始截图只保留在本机的 `source-templates/`，不会进入 `dist`。
- OCR 使用浏览器内的 Tesseract.js 和本地中文模型；图片不会上传到云端。低对比度或疑似漏检的值会在局部区域复核，并在仍不确定时显示“待核对”。
- 识别结果仍可能有错字或漏字，尤其是人名、地名和手写内容。编辑前请核对文字与画布位置，必要时修改字段名、调整偏移或框选补充。
- 文字区域采用附近的背景色覆盖，复杂背景、跨行文字或特别长的新内容可能需要进一步手工调整。
- 内置苍水行楷、霞鹜文楷、马善政毛笔、思源黑体和思源宋体，支持跨设备使用；手写混排依赖设备字体及替代字体，不同设备的字形可能不同。
- 当前修改只保存在本次浏览器会话，导出图片后请自行保存成品。

本地 OCR 资源由 `scripts/prepare-ocr.mjs` 从已安装的 Tesseract.js 包复制；中文模型位于 `public/ocr/chi_sim.traineddata`。
霞鹜文楷、马善政毛笔、思源黑体和思源宋体遵循 OFL 1.1，许可文本位于 `public/fonts/licenses/`。个人导入的字体不包含在项目中。
